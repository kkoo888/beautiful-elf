## 3. 开源项目社区评价

### 3.1 Aspects (10k+ Stars)

**项目概况**: Objective-C/Swift 的 AOP 库，截至 2026 年有 10,000+ Stars，167 Commits。

**正面评价**:
> "Aspects 是 iOS 生态中最经典、最轻量、最广泛采用的开源实现之一……核心代码不足千行，对应用性能影响极小。"

> "Think of Aspects as method swizzling on steroids."

- 来源: GitHub README [https://github.com/steipete/Aspects]; CSDN 技术分析
- 可信度: ⭐⭐⭐⭐⭐ 极高 — 项目 README 为一手信息

**负面评价 / 矛盾点 ⚠️**:

Peter 本人在 README 中明确警告不要在生产环境使用：

> "I STRICTLY DO NOT RECOMMEND TO USE Aspects IN PRODUCTION CODE."
> "Aspects uses _objc_msgForward which causes issues with other code that uses message forwarding."

**矛盾记录**: 尽管作者明确不推荐生产使用，该库仍被广泛用于生产环境（包括无埋点 SDK、性能监控等），被 7k+ 项目依赖。社区对此存在分歧——有人认为这是"负责任的诚实"，有人认为既然不推荐就不该发布。

- 来源: GitHub README [https://github.com/steipete/Aspects]; 简书无埋点方案 [https://www.jianshu.com/p/345d483b9f1a]
- 可信度: ⭐⭐⭐⭐⭐ 极高

### 3.2 Peertalk

GitHub 上的 Peertalk 项目用于 iOS 与 Mac 之间的 USB 通信。社区评价为"简洁实用"，但维护频率较低。

- 来源: GitHub (项目已被多次 fork，原 repo 维护状态一般)
- 可信度: ⭐⭐⭐ 中

> "2 天 10 万 Star！GitHub 史上增长最快的开源项目记录。"

> "一个叫 OpenClaw 的开源项目……是 PSPDFKit 创始人 Peter Steinberger 两个月前的一个周末项目。"

> "Mark Zuckerberg 和一位同事 Ned 整整一周都在玩他的产品，并不断给他反馈——'这个很棒'、'这个不行，得改'。"

- 来源: TechCrunch [https://techcrunch.com/2026/02/15/openclaw-creator-peter-steinberger-joins-openai/]; 腾讯云 [https://cloud.tencent.com/developer/article/2649045]

## 5. 与同行对比

### 5.1 vs Mattt Thompson (AFNetworking / NSHipster)

两者常被并列为 iOS 开发圈最有影响力的开源贡献者：

> "Mattt Thompson: creator of NSHipster, AFNetworking, and a lot more. Peter Steinberger: creator of PSPDFKit."

Mattt Thompson 曾引用 Peter 的工作：
> "'at least I can depend on ISO8601DateFormatter to get the job done.' – Mattt Thompson"
> "'Peter Steinberger's fork of SDURLCache is as useful as it is an impressive example of some fascinating optimization strategies.' – Mattt Thompson 引用"

- 来源: CSDN iOS Top Libraries [https://blog.csdn.net/fanbird2008/article/details/51914517]
- 可信度: ⭐⭐⭐⭐ 高 — Mattt Thompson 本人的评价

**差异**: Mattt Thompson 以教育内容 (NSHipster) 和基础设施库 (AFNetworking) 著称，Peter 以商业产品 (PSPDFKit) 和底层工具 (Aspects) 著称。Mattt 更偏"教师型"，Peter 更偏"工匠型"。

### 5.2 vs Chris Lattner (Swift 之父)

两者在 "52 位必关注 iOS 开发者" 列表中并列：
> "2. Chris Lattner — Swift programming language lead developer."
> "25. Peter Steinberger — iOS developer, author of an advanced iOS PDF framework."

**差异**: Chris Lattner 的影响力来自语言层面 (Swift)，Peter 的影响力来自应用层面 (PDF 渲染、AOP)。Chris 是 Apple 内部推动者，Peter 是独立开发者/创业者。

- 来源: 同上 52 人列表
- 可信度: ⭐⭐⭐ 中

### 5.3 vs objc.io 团队

> "objc.io 这个网站由世界级的 iOS 工程师每月进行更新……Peter Steinberger 本站为个人博客。"

两者在 iOS 深度技术内容上各有侧重：objc.io 偏架构和设计理念，Peter 偏性能优化和底层实现。

- 来源: CSDN iOS 学习资源 [https://blog.csdn.net/sun2728/article/details/51162610]
- 可信度: ⭐⭐⭐ 中

## 10. 综合评估

### 正面共识
- iOS 开发圈公认的 Top 级工程师，技术深度和广度兼具
- PSPDFKit 是 iOS PDF 领域的标杆产品，企业级口碑极好
- 开源贡献持续 10+ 年，Aspects 等项目影响深远
- 坦诚面对 burnout，具有人格魅力
- OpenClaw 展示了惊人的执行力和产品直觉

### 负面共识
- PSPDFKit 定价对独立开发者不友好
- AI-era 的 "Ship fast, don't read" 理念引发工程严谨性争议
- 与 Anthropic 的冲突中，部分人认为他也有责任（改名、立场模糊）
- 从"独立开发者"到"OpenAI 员工"的转变，让部分追随者感到背叛

### 尚无定论
- 他的技术风格是 "高效务实" 还是 "走捷径"？
- OpenClaw 的成功是个人能力还是时代红利？
- 加入 OpenAI 是明智选择还是放弃独立性？
